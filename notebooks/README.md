# Notebooks

Ce dossier regroupe les notebooks d'exploration, de validation et d'analyse du projet.

Notebooks prévus :

- `01_data_exploration.ipynb` : exploration des données Yahoo Finance et premiers contrôles.
- `02_indicator_validation.ipynb` : validation des indicateurs techniques.
- `03_news_indicator_analysis.ipynb` : analyse des indicateurs textuels.
- `04_strategy_backtest.ipynb` : expérimentation des stratégies.
- `05_strategy_comparison.ipynb` : comparaison finale des performances.

Les notebooks ne doivent pas contenir de secrets ni de credentials.
